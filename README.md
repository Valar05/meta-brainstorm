# Meta Brainstorm

Meta Brainstorm studies the machinery underneath creative work.

It is not an AI repo, a game-design repo, or a promise that every human art can be reduced to an algorithm. Its scope is broader and its claim is smaller:

> **All human creativity is in scope; human agency remains the purpose.**

The recurring question is:

> Which parts of a creative act can be understood, preserved, transferred, recombined, or made easier without pretending the remainder does not exist?

## Core loop

```text
HUMAN INTENT
-> EXPERIMENT / PERFORMANCE / ARTIFACT
-> OBSERVE WHAT ACTUALLY MATTERS
-> EXTRACT A REUSABLE CAPABILITY
-> MAKE THE CAPABILITY CHEAPER TO INVOKE
-> SHIP SOMETHING USEFUL
-> LOWER THE COST OF THE NEXT IDEA
```

Artifacts are valuable. Reusable capability is compound interest.

## Founding doctrines

### Capability over artifact

Do not preserve only the finished thing when the law that generated the useful part can also be preserved.

```text
artifact -> lesson -> tool -> capability -> cheaper next artifact
```

### Toys before monuments

A little toy can be complete work. It should have present-tense value: **shippable, useful, or both**. If it also becomes engine capability, that is accumulated leverage rather than an excuse to postpone delivery.

### Bad House / Good House

A **Bad House** makes the user's activity serve the house more than the house serves the activity. Common symptoms include recurring permission, extraction, artificial scarcity, lock-in, justification taxes, and incentives that bend the work away from its own purpose.

A **Good House** increases agency. Understanding it increases freedom. Useful knowledge survives the current project. The person can leave with more capability than they entered with.

### Open capability

Open source can convert many permission problems into engineering problems. That does not eliminate licensing, hardware, money, distribution, or difficulty. It changes the location of authority: the mechanism can be inspected, modified, preserved, and taught.

### AI is bootstrap, not foundation

AI is a current tool for discovering and translating capability. It is not the point.

```text
flexible intelligence
-> discover the rule
-> make the rule explicit
-> compile downward when possible
-> deterministic script / solver / state machine / test / data
```

A successful AI workflow should repeatedly ask:

> **What happened here that still genuinely requires an AI call?**

If the answer is "nothing; the mechanism is understood now," preserve the mechanism somewhere the provider cannot take it back.

### Decomposable authorship

Do not confuse the industry that currently manufactures a medium with the capabilities required to create in that medium.

Games are a useful first laboratory because they already combine story, image, animation, acting, sound, music, architecture, choreography, interface, systems, and audience participation. But the research boundary is not games.

Writing, illustration, sculpture, animation, music, film, theater, craft, choreography, architecture, cooking, fashion, performance, interaction, and forms not yet named are all eligible for the same question.

Some creative knowledge will remain situated, embodied, tacit, relational, culturally specific, or simply unknown. That remainder is not a failure of the theory. It is part of the map.

## Promotion rule

An idea belongs here when it survives its original example and becomes useful across domains.

A strong Meta Brainstorm entry should answer:

1. **What capability was discovered?**
2. **What artifact or experiment exposed it?**
3. **What part transfers?**
4. **What remains situated or uncertain?**
5. **How can the capability become cheaper, more durable, or more communal?**
6. **What would falsify or bound the claim?**

## Repository family

- [`Valar05/thunder-brainstorm`](https://github.com/Valar05/thunder-brainstorm) mines games, prototypes, mechanics, workflows, and project scars for reusable patterns.
- [`Valar05/tactics-brainstorm`](https://github.com/Valar05/tactics-brainstorm) tests systems ideas against tactics, history, authority, persistence, and recomposition.
- **Meta Brainstorm** receives the patterns that cross those domains and become theories about capability, authorship, tools, institutions, and creative agency itself.

The relationship is intentionally porous:

```text
SPECIMEN
-> DOMAIN THEORY
-> CROSS-DOMAIN THEORY
-> TOOL / TEST / DOCTRINE
-> NEW SPECIMEN
```

## Initial structure

```text
doctrine/     durable cross-domain claims
patterns/     reusable mechanisms and design laws
cases/        specimens that stress-test the theory
bridges/      explicit mappings between creative domains
questions/    unresolved research threads and falsifiers
```

## North star

> **Make the distance between human intent and a real, inspectable creative consequence smaller, while increasing the human's custody of what happens next.**
