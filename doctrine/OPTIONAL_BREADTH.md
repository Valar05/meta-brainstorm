# Optional Breadth

**Date:** 2026-09-14
**Status:** candidate cross-domain doctrine

## Origin specimen

Last Convoy can be complete with a very small set of convoy vehicle roles while still exposing a clean seam for many more.

The important distinction is:

```text
SYSTEM COMPLETENESS != CATALOG COMPLETENESS
```

A small role set can prove the grammar. Additional roles can remain optional modules rather than prerequisites for legitimacy.

## Healthy extension seam

A system has healthy optional breadth when:

```text
three modules -> complete artifact
fifteen modules -> broader artifact
stopping anywhere between -> still valid
```

This protects purity because expansion does not require new player-facing verbs or a new central thesis. New modules enter through an already-proven relationship.

## Relation to fruit density

Optional breadth differs from obligatory scope.

Obligatory scope says the artifact is not finished until enough content exists.

Optional breadth says the artifact is already finished, and more content is merely another way to enjoy or explore the existing grammar.

This lowers stakes for creation and makes abundance non-coercive.

## Candidate rules

> **Finish the grammar early; leave the catalog open.**

> **The best extension seam makes both stopping and continuing feel legitimate.**

> **A system may be complete while its possibility space remains deliberately unfinished.**
