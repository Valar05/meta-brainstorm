# Regime Coverage

**Date:** 2026-09-14
**Status:** active doctrine / promoted from HEMA and game-design observations

## Observation

A narrow action vocabulary can still create a wide decision space when the available actions control very different regimes.

Drew's remembered sparring example is bimodal: one mode preserves maximum measure with cautious long-range pressure; the other collapses measure through strong commitment. The useful abstraction is not the number of techniques. It is the number and separation of state regimes those techniques threaten.

```text
REPERTOIRE WIDTH != DECISION-SPACE WIDTH
```

A system with two actions can be strategically rich if each action changes the opponent's problem in a qualitatively different way.

## Regime coverage

Let actions `a_i` map the current state into different response regimes `R_i`.

```text
small action set
+ strongly separated regimes
+ legible consequences
= large decision burden
```

The important quantity is therefore not simply action count, but **regime coverage**: how much distinct future-state territory the action set can reach or threaten.

This connects directly to `CONTACT -> CONSEQUENCE -> ADAPT`. Each contact matters when it can move the system into a different regime that changes what a sensible next action is.

## Game-design consequence

Small games do not need large verb lists to be deep. They need verbs whose consequences differ enough to force adaptation.

Armor Command is a strong adjacent example: a very small touch grammar covers materially different regimes because tap/hold timing, rack cooldowns, gunfire, branching enemy states, and additive mutations alter what the player must solve next without requiring a large control vocabulary.

This also explains why scope can deepen without widening. New content is valuable when it gives existing actions new regime consequences rather than merely adding more nouns.

## Animation consequence

Strong anticipation and strong commitment can encode opposite ends of a motion/state continuum without densely authoring every intermediate state. Semantic extrema can therefore create both readable animation and strategic meaning.

## Boundary

This is not a claim that fewer actions are always better. If two actions lead to effectively the same regime, compression only removes expressive power. The hypothesis predicts richness when the actions are few **and** their downstream consequences are structurally distinct.

## Compact doctrine

> **Few actions are enough when they control different regimes.**

> **Repertoire width need not equal decision-space width.**

> **Depth comes from consequential separation, not from verb count alone.**
